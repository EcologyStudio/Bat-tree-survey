CSV Export

Standard comma-separated file for Excel, QGIS, or ArcGIS. Multiple features export as separate rows sharing the same tree reference.

GeoJSON for QGIS

Exports a .geojson point layer with all tree attributes. In QGIS, simply drag and drop the file — no import wizard needed. CRS is EPSG:4326 (WGS84); reproject to NZTM2000 as required.

Summary Report

Generates a professional Preliminary Roost Tree Assessment memorandum. Includes session details, survey summary, per-tree results table, field photos, and management recommendations. Opens in a new tab — use Print → Save as PDF.
